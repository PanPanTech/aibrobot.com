Wi-Fi requirements depend on **the feature you want to use**. AIB Robot's [164 cm expression-head figure with head #1068](/ai-robots/wm-164-f-1068) is described as needing a working network for its facial-expression features. The public listing gives no assurance that its connected features already work on US or EU home Wi-Fi. The optional [voice box](/voice-box) is a separate audio accessory described as independent of that connection. A conventional posed figure can be posed manually.

## Match the connection to the function

Ask about the specific behavior you expect to use after setup. Speech input, spoken replies, facial movement and connection to a local control device are separate actions. Ask which steps require a router, which require internet access, and what still works during a service interruption.

| Function or component | What the current listing establishes | What to ask before purchase |
| --- | --- | --- |
| Facial expressions on head #1068 | A working network connection is required for the described expression features | Can someone demonstrate the behavior on the exact revision for your destination? |
| Spoken conversation | The supplied notes describe a voice platform, microphone and speakers. US or EU home-network operation needs confirmation | What languages, service, account and setup are required? |
| Touch display | The notes list a touch display | Which controls remain available if internet service is interrupted? |
| Bluetooth | Listed alongside Wi-Fi | What can be paired and what does pairing enable? |
| Optional voice box | Audio add-on described as independent of the head's home Wi-Fi connection | How is audio started, powered, stopped and adjusted? |

In everyday use, a device can connect to the local router and still be unable to reach a particular internet service. Establish both parts of the setup. If successful interaction depends on an account or a service reachable from your country, obtain the name of that service and confirm its requirements. For the product scope and physical setup, see the [expression-head guide](/blog/ai-bionic-and-expression-robots).

## Check US or EU operation before dispatch

Give the seller the destination country and the type of network you expect to use. A normal residential router, a shared building network, a phone hotspot and a workplace network can have different sign-in rules. If the instructions require a mobile device or a timed setup step, confirm the supported system and whether you need a local app-store account. Keep your actual Wi-Fi password and your account credentials private.

Ask for the head identifier and firmware version, followed by current written setup instructions. For the network itself, ask which frequency bands and authentication modes the device supports. AIB Robot's public notes establish Wi-Fi and Bluetooth interfaces but provide no verified band or router compatibility list. A band listed for another product or a successful connection on a different head revision is weak evidence for your order.

If there is a demonstration, check which configuration and connection it uses. A video can show how the device behaves during one successful session. It usually cannot establish that your app store, router or remote service will work the same way. Ask what can be checked before payment and what can be checked on the actual unit before dispatch. Keep the answers with your order, including what the seller offers if any agreed behavior does not work on arrival.

## Ask for a demonstration in the order you will use it

A demonstration should follow a normal session. Confirm that the device starts, connects as instructed, accepts an input and responds. If a feature is essential, ask to see it behave after a restart. If offline operation matters, ask the seller to show a temporary internet disconnection using the supplied setup and identify what the device can still do. Record results feature by feature.

| Step | What to observe |
| --- | --- |
| Turn on | The head and its control screen start using the supplied power equipment |
| Set up | The seller identifies the version, network type and any app or account used |
| Speak and listen | The device handles a fresh request and replies in the language you need |
| Check facial movement | The required expression is demonstrated under the stated connection |
| Restart | The device reconnects using the documented method and repeats the essential interaction |
| Assess an interruption | The test explicitly identifies what happens to the display, audio and expression functions |

Ask to see a fresh spoken request rather than relying on a clip that starts midway through an interaction. If you need a particular language, include a simple everyday request in it. If you care about how quietly or quickly the system responds, ask for that test with sound recorded at a useful distance. For a separate voice box, ask for its own demonstration. The [voice box guide](/blog/ai-voice-box-guide) covers questions about controls, installation and power.

## Check the service and network settings

Find out whether you need a separate service account and what information it collects. For a microphone or connected conversation service, request the specific privacy notice, who operates the service, whether conversations or saved questions are stored and how you can delete them or reset the device. Ask where account and device resets are documented. For an essential function, save the written service requirements with the order. The [cost guide](/blog/ai-companion-robot-price) explains where to record an account fee if one applies.

Use your router's encrypted Wi-Fi and up-to-date software while setting up connected equipment. The FTC also advises changing default router credentials and using a guest network to limit access to the main network. A separate network is an option if the device's instructions support it. If setup requires the phone and head to communicate locally, confirm whether network isolation would prevent that step. [Read the FTC's home Wi-Fi guidance](https://consumer.ftc.gov/articles/how-secure-your-home-wi-fi-network).

Check the physical installation at the same time. Ask what charger and power requirements apply to the supplied unit, where the microphone and controls are located and how to power down before storage or cleaning. Place the head according to its instructions and allow normal ventilation. Use the [first-week setup guide](/blog/first-week-unboxing-and-setup) to record the package condition and check the configuration before routine use.

## Record what you see during the first setup

Before starting, photograph the package label and match the head identifier and supplied accessories against your order. Read the current instructions for the voltage, charger and connector before applying power. Write down the test date, the installed firmware if it is displayed, and the source of the setup guide. An observed result for your unit gives the seller more useful information if you need help later.

If the head powers up but refuses to join the network, record the stage and visible error message. Check the supported network type against the documentation before changing router settings. If it joins the router but fails to sign in, record the sign-in stage and whether the requested service is available in your country. If it signs in but fails to respond, write down which input and output failed and whether the problem recurs after a normal restart. Remove any account data or private conversation content from the materials you share with support.

A partial result still tells you something. Working touch controls are evidence for the screen, and a spoken response is evidence for the speech test. Check expression movement separately and record whether the two functions succeed in the same session. For intermittent faults, identify whether the problem happens after idle time, after restart or during a particular action. Where the outcome differs from the agreed setup, collect that short record and use the support contact before attempting repairs or repacking the electronics.

## Send a written connectivity request

Name the exact feature and the destination so the seller can check the correct component and operating conditions. Use something like this as a starting point:

> I'm considering the 164 cm F-cup figure with expression head #1068 for use in my country. I need spoken replies in English and the listed facial expressions on a home router. Please tell me the head and firmware version, supported router settings, any required app or account and the current setup procedure for my country. Can you demonstrate both features on the version quoted and explain what still works if internet access is lost? Please confirm what you can check before I pay and what you can verify before dispatch.

Add any requirement you already know about, such as a phone hotspot, a separate guest network or use without a phone after initial setup. Ask about that requirement directly. If the reply confirms audio but leaves expressions unresolved, keep the expression line open and ask for a separate answer.
